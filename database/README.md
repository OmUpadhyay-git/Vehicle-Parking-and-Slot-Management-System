# Database

This folder contains the database schema and related files for the Vehicle Parking and Slot Management System.

## Technology

- Database: MySQL
- ORM: SQLAlchemy (via Python backend)

## Tables

1. `users` - User accounts and roles
2. `vehicles` - Vehicle registration information
3. `parking_slots` - Parking slot configuration
4. `parking_records` - Vehicle entry/exit records
5. `payments` - Payment records
