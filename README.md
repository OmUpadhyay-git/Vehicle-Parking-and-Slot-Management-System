# Vehicle Parking and Slot Management System

A desktop-based parking management system for managing vehicle entry, parking slot allocation, vehicle exit, parking fees, and payment records.

## Technology Stack

| Layer | Technology |
|-------|------------|
| Frontend | Java |
| UI Framework | Java Swing |
| Backend | Python |
| Backend Framework | FastAPI |
| Database | MySQL |
| ORM | SQLAlchemy |
| API Communication | REST API |
| Version Control | Git |
